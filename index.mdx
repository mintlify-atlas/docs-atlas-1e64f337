Linea is a header-only C++20 linear algebra engine. Drop a single `#include <Linea.hpp>` into your project and get dense vectors, matrices, four numerical decompositions, and element-wise math functions — all enforced at compile time through C++20 concepts with zero runtime overhead.

## Get Started

<Steps>
  <Step title="Copy the headers">
    Clone the repository or copy the `include/` directory into your project. No build step required — Linea is header-only.
  </Step>
  <Step title="Include the umbrella header">
    Add `#include <Linea.hpp>` to your source file. This pulls in all modules: Core, Vector, Matrix, Decompositions, and I/O.
  </Step>
  <Step title="Compile with C++20">
    Pass `-std=c++20` (GCC/Clang) or `/std:c++20` (MSVC) to enable the C++20 concepts that Linea relies on.
  </Step>
  <Step title="Write linear algebra">
    Create vectors, build matrices, run decompositions, and display results — all with full type safety enforced at compile time.
  </Step>
</Steps>

<Note>
  Linea requires a C++20-compliant compiler. GCC 10+, Clang 12+, and MSVC 19.29+ are supported.
</Note>
